# YOASOBI 歌詞學習

> 一起練習，一起唱到北海道。  
> by Terry878 · 非官方歌詞學習網站

**[開啟網站](https://demo.terry878.org/lyricprompt/)**

## 我的動機與心得

為了準備到北海道聽 YOASOBI 演唱會，我用 Codex 做了這個歌詞練習網站。希望在出發前熟悉歌曲，練習日文歌詞和發音；也希望喜歡 YOASOBI 的大家能一起練習，在演唱會上盡情歡唱。

做這個網站的過程中，我一邊使用、一邊調整，希望它在手機和電腦上都能方便閱讀。歌詞、翻譯和同步時間仍可能有誤，我會繼續改善，也歡迎分享需要修正的地方。

## 如何使用

1. 打開[網站](https://demo.terry878.org/lyricprompt/)，從專輯、單曲或搜尋結果中選歌。
2. 在頁面上的 YouTube 播放器按播放。歌曲開始後，當前歌詞會醒目標示並隨播放位置前進。
3. 閱讀日文、假名、羅馬拼音與中文翻譯；點選歌詞可跳到該句附近。翻譯與假名請搭配原詞確認。
4. 若開頭時間有偏差，打開「設定」，在聽到第一句時按「現在是第一句」，或用「提早／延後」微調，再按「儲存」。這會調整整首歌的共同偏移，不代表後續每一句都已逐句校準。
5. 儲存的校準值留在目前的瀏覽器。想提供給我參考時，可在「設定」按「分享已儲存的校準」，將畫面顯示的代碼傳給我；我確認後可更新網站的預設時間。

網站支援手機與電腦。返回唱片架時，已載入的播放器可繼續播放；部分影片的可播放性由 YouTube 及權利人設定決定。

## 資料與隱私

- 歌詞來源會顯示在歌曲頁面；歌詞、翻譯、曲名、專輯封面與影片的權利屬於各自權利人。本專案是非官方的學習用途，沒有宣稱取得額外的內容授權。
- 部分中文與讀音由工具產生或經 AI 修正，可能有誤。來源與工具資訊可在歌曲頁的「原詞」處查看。
- 個人時間校準保存在瀏覽器中。只有主動按「分享已儲存的校準」時，歌曲版本與校準時間才會送至服務端；分享紀錄會在 14 天後自動刪除。分享功能不會上傳錄音。
- 頁面包含 YouTube 播放器和外部圖片，相關服務可能收到必要的連線資訊。

## 關於這個儲存庫

`docs/` 只包含 GitHub Pages 顯示網站所需的靜態檔案。本機測試資料、模型、配對資訊和錄音不包含在儲存庫中。校準分享服務由既有的 Cloudflare Worker 提供；本站網址會轉送 GitHub Pages 的頁面內容。

要更新 GitHub Pages，修改 `docs/` 中的網站檔案並推送到 `main`；GitHub Pages 會重新部署。校準分享後端仍由 Cloudflare Worker 處理，不在 GitHub Pages 上執行。
